# Add a note to your answer

Explain your answers, like when you can only stay for part of the time. This guide is for people invited to a poll.
{/* aida:end header */}

{/* aida:begin steps-heading */}
## Steps
{/* aida:end steps-heading */}

{/* aida:begin step-mark-dates */}
#### 1. Mark your dates

Mark the dates that work for you in the **You** row, then select **Continue**.

*On a computer only.*

![Screenshot of New participant: mark the dates that work for you in the You row, then select Continue.](screenshots/step-01.png)
{/* aida:end step-mark-dates */}

{/* aida:begin step-mark-dates-phone */}
#### 2. Mark your dates

Under each date, tap **Yes**, **If need be** or **No**, then select **Continue**.

*On a phone only.*

![Phone screenshot of Mark your dates: under each date, tap Yes, If need be or No, then select Continue.](screenshots/phone-step-02.png)
{/* aida:end step-mark-dates-phone */}

{/* aida:begin step-open-note */}
#### 3. Add a note

Type your name in **Name**, then select **Add a note**.

<DeviceShots devices="desktop,phone">

![Screenshot of Add a note: type your name in Name, then select Add a note.](screenshots/step-03.png)

![Phone screenshot of Add a note: type your name in Name, then select Add a note.](screenshots/phone-step-03.png)

</DeviceShots>
{/* aida:end step-open-note */}

{/* aida:begin step-write-note */}
#### 4. Write your note

Type your note in **Note for the organizer**. Only the organizer sees it, not the other people on the poll.

<DeviceShots devices="desktop,phone">

![Screenshot of New participant: type your note in Note for the organizer. Only the organizer sees it, not the other people on the poll.](screenshots/step-04.png)

![Phone screenshot of New participant: type your note in Note for the organizer. Only the organizer sees it, not the other people on the poll.](screenshots/phone-step-04.png)

</DeviceShots>
{/* aida:end step-write-note */}

{/* aida:begin step-save */}
#### 5. Save your availability

Select **Save availability**. The organizer sees a note icon next to your name and can read it there.

<DeviceShots devices="desktop,phone">

![Screenshot of Save your availability: select Save availability. The organizer sees a note icon next to your name and can read it there.](screenshots/step-05.png)

![Phone screenshot of Save your availability: select Save availability. The organizer sees a note icon next to your name and can read it there.](screenshots/phone-step-05.png)

</DeviceShots>
{/* aida:end step-save */}
